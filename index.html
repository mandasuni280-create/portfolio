About me

Curious about how useful software gets built.

I’m currently a first-year student at Multimedia University. Alongside my studies, I’m self-driven in my learning, always seeking knowledge and working to advance my skills.

I’m an aspiring software developer who wants to build useful digital products and solve real problems. My foundation is Python and Django, and I’m comfortable with basic Django REST Framework CRUD operations while I keep sharpening my API skills.

On the frontend, I’m open about my approach: I use AI-assisted tools and design workflows to create modern React and Tailwind CSS interfaces. My strength is directing and customizing those experiences, not writing frontend code from scratch on my own.

I also use Make.com to explore simple automations for small businesses, and I’m now learning Generative AI, LLMs and how to connect them to backend applications. The long-term goal is a company that builds valuable software.
